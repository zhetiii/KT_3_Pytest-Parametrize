# Контрольная точка №3. Проектирование и автоматизация тестов (Pytest Parametrize)

## Описание задания
Реализация и автоматизация набора параметризованных тестов с использованием фреймворка `pytest` и библиотеки `ipytest` в формате Jupyter Notebook (`.ipynb`).

* **Дисциплина:** Тестирование программного обеспечения
* **Вариант:** Вариант 1 (Pytest Parametrize)

---

## Содержание работы

1. **Задание 1. Функция `is_even(number)`**
   * Проверка чётности целых чисел с использованием `@pytest.mark.parametrize`.
   * Отдельный блок негативных тестов на передачу некорректных типов данных (`TypeError`).

2. **Задание 2. Функция `calculate_area(length, width)`**
   * Расчёт площади прямоугольника для различных комбинаций сторон.
   * Проверка обработки некорректных (отрицательных) значений (`ValueError`).

3. **Задание 3. Функция `classify_triangle(a, b, c)`**
   * Определение типа треугольника (равносторонний, равнобедренный, разносторонний).
   * Негативные тесты на нулевые/отрицательные стороны и нарушение неравенства треугольника.

4. **Задание 4. Доработка функций из КТ-2**
   * Параметризация тестов для функций измерения длины строки, сохранения текста в файл (с использованием `tmp_path`) и операций с базой данных SQLite (`pytest.fixture`).
